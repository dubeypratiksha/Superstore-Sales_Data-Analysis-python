Superstore Sales Analysis Project

Project Overview:-   
This project analyzes the Superstore dataset using Python, Pandas, and data visualization libraries to uncover sales and profitability insights.

Objective:-  
To analyze sales performance, identify profitable segments, and provide actionable business insights.

Tools Used:-  
Python  
Pandas  
NumPy  
Matplotlib  
Seaborn  
Google Colab  

Key Analysis:-  
Sales by Category
Profit by Region
Monthly Trends
Discount vs Profit Impact
Feature Engineering (Shipping Days, Profit Margin)

Key Findings:-  
Technology category drives highest revenue.
High discounts reduce profit.
Some sub-categories operate at a loss.
Regional performance varies significantly.

Conclusion:-  
Data-driven decisions regarding discount policies and product focus can significantly improve profitability.
